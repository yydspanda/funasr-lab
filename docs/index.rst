FunASR Documentation
====================

Build speech applications with the right model, a reproducible inference path,
and explicit deployment boundaries.

The `product documentation <https://www.funasr.com/en/docs/>`_ and
`Chinese documentation <https://www.funasr.com/docs/>`_ provide a searchable
entry to these guides. Source Markdown remains in this repository.
