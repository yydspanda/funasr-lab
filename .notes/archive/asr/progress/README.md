# ASR Progress Archive

When [`progress.md`](../../../asr/progress.md) exceeds ten recent terminal records, move the
oldest records into `YYYY-MM.md` in this directory. Preserve their original
date, Roadmap task ID, terminal status, outcome, and verification evidence.

Archive files are history, not active execution pointers. They must not contain
`Current Stage` or `In Progress Task` fields.
